## 3. Arah visual dari compro

- **Warna**: hijau tua `#006636` (judul, footer bar, bidang gelap), hijau `#0c9042` (ikon lingkaran, aksen), gradien hero `#06843c → #0c9042`, overlay hijau `#187248`/`#24784e` (foto di atas hijau), netral teks `#363636`, abu muda `#f4f4f4`, putih. Logo: hijau `#006838`/`#089040`.
- **Tipografi**: compro memakai **Poppins** (Light/Regular/Medium/SemiBold/Bold) untuk isi dan **Cocogoose Pro Trial** untuk judul besar ("COMPANY PROFILE", "WHO WE ARE"). Cocogoose versi *Trial* tidak berlisensi untuk web; website memakai Poppins ExtraBold/Bold untuk judul besar kecuali klien menyediakan lisensi Cocogoose Pro (OPEN-QUESTIONS #6).
- **Motif**: bidang diagonal hijau (sudut ±25–30°, satu sisi halaman), watermark kubus logo transparan di latar, ikon garis putih dalam lingkaran hijau, kartu putih dengan bayangan lembut dan garis hijau di atas, garis pembatas hijau tebal di footer. Foto: gedung CBD Jakarta, globe, signage kantor marmer, interior kantor.
- Tidak ada warna emas (brand ABN) atau maroon (Apegale) di website ini.
